# LUMEN 光学实验室

安装依赖：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`，生产构建：`npm run build`。

单元测试：`npm test`

Docker 启动：`docker compose up --build`，访问 http://localhost:18110 。

## 历史与分支

- 每次变更（添加、移动、调参、移除、切换/重置任务）都会成为历史节点；
  拖动与滑块等连续调节按 1.2 s 时间窗聚合为单个节点。
- 左侧「历史与分支」面板可跳转当前分支的任意节点、从任意节点创建
  命名分支；在分支中段继续编辑会自动分出新分支，原分支保持可访问。
- 分支行上的比较按钮进入比较模式：参考分支的光路以虚线叠加在实验台，
  比较栏并排显示两条分支的接收屏测量（只读，不写入当前场景），
  可一键采用参考分支。
- 保存后重开，分支结构、器件身份与任务上下文完整恢复。
